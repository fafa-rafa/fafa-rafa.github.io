PockPlay

A simple two button game console. A pocket console for the ESP32-C3 SuperMini with a 0.96" SSD1306 OLED and just two buttons (UP / DOWN).

C++GPL-3.0ESP32-C3OLED

Games

CalcDodgerDino RunPongFroggerFlappySnakeBreakout

Tool

TV-B-Gone (IR power-off blaster, USA/Canada and Europe/Asia code sets)

High scores are saved to flash and shown in the menu.

Hardware

PartConnection
OLED SDA / SCLGPIO5 / GPIO6 (3V3, GND)
UP buttonGPIO3 to GND
DOWN buttonGPIO4 to GND
Passive buzzer (optional)GPIO10 to GND

Power: 1S LiPo through a TP4056 protection module to the 5V pin via a switch. Never plug USB into the SuperMini while the battery is connected.

Install: option 1, esptool by spacehuhn

  1. Go to the releases page and download the binary file
  2. Open esp.huhn.me and connect the ESP
  3. Upload the binary, flash, wait, reboot. Done!

Install: option 2, build

  1. Install the Arduino IDE and the ESP32 core 3.x (needed for tone() and the LEDC API)
  2. Install the libraries Adafruit SSD1306 and Adafruit GFX
  3. Open PockPlay_V0_2/PockPlay_V0_2.ino, select ESP32C3 Dev Module, enable USB CDC On Boot for serial output, and upload

Controls

  • Menu: UP / DOWN scroll, press both to start
  • In game: hold both for about 0.7 s to return to the menu
  • TV-B-Gone: UP = USA/Canada codes, DOWN = Europe/Asia codes, hold both to stop
